# my-apps

All my app projects in one repo, built stage by stage with Claude Code.

| App | Folder | What it is |
|-----|--------|-----------|
| Short-form blocker | `apps/shorts-blocker` | Chrome extension that hides Shorts/Reels/TikTok |
| Have you ever wondered | `apps/wondered-site` | Q&A site for everyday STEM questions, home of the YouTube channel |
| Media log | `apps/media-log` | Letterboxd + AniList for movies, series, anime, manga, books, games |
| Wellbeing | `apps/wellbeing-app` | 5-minute daily check-in, habits, streaks shared with a friend |
| Budget | `apps/budget-app` | Quick, guilt-free budgeting + paper trading to learn investing |
| Workout | `apps/workout-app` | Routine builder, workout log, Reddit-style split sharing |
| Study tools | `apps/study-tools` | Spaced-repetition flashcards, focus timer, practice generators |

- `PROGRESS.md`: what's done and what's next
- `SETUP-NEEDED.md`: accounts, keys and choices waiting on me
- `apps/<name>/LEARNING.md`: what I learned in each stage
